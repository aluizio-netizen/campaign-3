# United Nations & Model UN — delegate workspace (Aluizio Pires Education)

**English** version of the static Model UN preparation site (HTML + CSS + JS, no
backend), for the domain **unitednations.aluizio.education**. The student's
progress is saved automatically in the browser (`localStorage`) — nothing is sent
to any server. It mirrors the Portuguese site at `onu-site/` (onu.aluizio.education).

## Sections
Course (session-by-session plan), Glossary (with search), Bodies (which body for
which problem), Procedure (motions cheat sheet), Documents (Position Paper & Draft
Resolution editors that auto-save), Funding (step-by-step), Blocs, Opening speech,
Checklist, Self-assessment rubric, and a solved Example (Horn of Africa crisis).

## Run locally
Open `index.html` in a browser, or serve it:

```bash
cd un-site
python3 -m http.server 8000   # http://localhost:8000
```

## Publish at unitednations.aluizio.education (Netlify)
Create a **separate** Netlify site connected to this repo and set, in the site
settings, the **Base directory = `un-site`** (build command empty). With that base,
Netlify reads `un-site/netlify.toml` (publish `.`) and ignores the root Next.js app.
Then add the custom domain `unitednations.aluizio.education` and create a CNAME
record (`unitednations` → your-site.netlify.app, **DNS only / grey cloud**) in
Cloudflare, exactly like the Portuguese site.

## Brand / customization
Same identity as the PT site: logo in `assets/` (generated by
`scripts/gerar_logo_aluizio.py`); palette in `assets/styles.css` (`:root`); all
text lives in data structures at the top of `assets/app.js`.
